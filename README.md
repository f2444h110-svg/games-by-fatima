# Bounce Riot

A fast, colorful arcade bounce game built with React and Vite. Move, jump, bonk rivals, and collect coins across 3 increasingly chaotic levels before the clock runs out.

## Features

- Start menu with controls guide and How to Play instructions
- 3 levels with unique arena layouts and increasing AI difficulty
- Keyboard controls: WASD / Arrow keys to move, Space / J to jump & bonk
- Pause menu (Pause button or Escape) with Resume, Restart Level, and Back to Menu
- Score, timer, and level HUD
- Responsive layout for desktop and mobile

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local dev server
- `npm run build` — build for production
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint
